FAQ

Questions, answered.

Does Agent push directly to main?

Never. Agent always works on a branch and opens a pull request. Protected-branch rules and required reviewers apply exactly as they do for your team.

Which languages does it support?

First-class support for TypeScript, Python, Go, Java, Rust, Ruby, and C#. Anything else works too, just with less deep static analysis.

Is my code used for training?

No. Your code and prompts are never used to train models, and we support zero-retention agreements on Team and Enterprise plans.

Can I self-host?

Yes — Enterprise customers can run Agent inside their own VPC or on-prem, with runners that never leave your network.

What happens when I hit my minutes?

Agent pauses new tasks and tells you. You can top up from the dashboard or upgrade — running tasks are never killed mid-PR.
